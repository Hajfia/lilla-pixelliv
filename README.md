# Mitt lilla pixelliv

```
  .------------------------------------.
  |      |                 |      .--. |
  |     /_\               /_\     |  | |
  |  +---+---+         +---+---+  |  | |
  |  |   |   |         |   |   |  | o| |
  |  +---+---+         +---+---+  |  | |
  |   _______                     |  | |
  |  |_______|o     /\_/\         |  | |
  |__|_______|____( o.o )_________|__|_|
  | / / / / / / / / / / / / / / / / / /|
  '------------------------------------'
```

Ett litet pixelrum för de minsta. Klicka på saker som lyser,
tänd och släck lamporna, låt dagen bli natt och ta hand om ett eget
litet husdjur.

## Vad finns i rummet?

- klickbara föremål som lyser upp när man hittar dem
- lampor och fönster som växlar mellan dag och natt
- ett husdjur att mata och gå ut med
- en liten mp3spelare

Allt sparas i webbläsaren, ingen inloggning och ingen server.

## Byggt med

React, TypeScript, Vite, Zustand, Motion och SCSS.

## Kom igång

```
npm install
npm run dev
```

`npm run check` kör lint, typecheck och type-coverage.
